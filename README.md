# Vídeos de Vértice

Vídeos listos para publicar. Metricool los descarga desde aquí (enlace público) cuando se programan en su calendario.

- `videos/AAAA-MM-DD_tema.mp4`: vídeo final (1080×1920, H.264 + AAC).
- `portadas/AAAA-MM-DD_tema.jpg`: portada.
- `calendario.md`: qué se publica, cuándo y con qué texto.

Ojo: el repositorio es público, así que cualquiera con el enlace puede ver los vídeos.
